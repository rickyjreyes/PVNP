## Scope

The revised Part I describes a **conditional, model-relative curvature-separation program**, not a proof of classical P ≠ NP. Part II proves the discrete finite-state, uniform-machine equivalence with classical P and NP, while separately identifying physical curvature realizability as an open bridge.
