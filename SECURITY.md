# Security and privacy reporting

The PVNP repository is a research project. Please **do not open a public issue containing credentials, private data, unpublished patent-sensitive material, or a proof-of-concept exposing another person's systems**.

Before public release, maintainers must complete a full-history and asset audit, review findings privately, and rotate/revoke exposed credentials if any are discovered. Removing a value in the newest commit does not erase historical exposure.

If GitHub private vulnerability reporting / repository security advisories are enabled, use that channel. Otherwise contact the repository owner through a private, pre-existing communication channel. Do not publish secret values to GitHub issues, PR comments, or audit logs.

This file does not claim that a security audit has passed. See [public-release readiness](PUBLIC_RELEASE_READINESS.md) and [licensing decision](docs/PUBLIC_LICENSE_DECISION.md).
