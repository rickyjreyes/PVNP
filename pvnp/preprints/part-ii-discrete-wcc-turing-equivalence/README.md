## Result

The revised manuscript develops polynomial-time equivalence between deterministic uniform **discrete finite-state** WCC machines and classical Turing machines and extends the verifier-based correspondence to NP.

## Scope / limitations

- Encoding, decoding, lattice construction, and machine specification must be uniformly polynomial-time effective.
- Exact wave–symbol evolution correspondence requires the appropriate compatibility (semiconjugacy) hypothesis.
- Physical PDE implementation under curvature-energy rails is an additional, unresolved resource-preservation question.
- No classical `P != NP` claim is made.
