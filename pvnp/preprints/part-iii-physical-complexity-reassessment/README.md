## Corrected scope

This revision addresses ten issues, WIN-12 through WIN-21, including zero-curvature distinguishability, unsafe shifted denominators, finite-energy regularity gaps, the conditional curvature-capacity law, physical P/NP class consistency, expander embedding gaps, witness admissibility, and the exact normalization and upper bounds for Boolean total influence.

**No physical or classical P ≠ NP theorem is claimed.** The bound on normalized Boolean total influence is at most n for any n-variable Boolean function. No universal WCT curvature lower bound is established.
